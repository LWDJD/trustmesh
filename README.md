# 社交信任计算：数学模型与实现

Rust 实现，零外部依赖。`cargo test` 全部通过，`cargo run --release --bin simulate` 输出验证报告。

## 1. 数学模型

### 1.1 符号

- `N`：用户数
- `W`：N×N 行归一邻接矩阵，`W[s][v]` 是 s 分配给 v 的相对权重
- `P`：N×N 评分矩阵，`P[s][u]` 是 s 对 u 的直接评分，取值 `[0,1]`
- `β`：个人权重，`1-β` 是群体权重

### 1.2 不动点方程

信任矩阵 `Π` 定义为：

```
Π = β·P + (1-β)·W·Π
```

`Π[s][u]` 的含义：观察者 s 眼中 u 的可信度。

展开后，它是「自己的直接评分」与「邻居视角的加权平均」的递归混合。

### 1.3 解

```
Π = β·(I - (1-β)·W)⁻¹·P
```

### 1.4 三条定理

**存在唯一。** W 行随机，谱半径 ≤ 1，所以 `(1-β)W` 的谱半径 ≤ 1-β < 1，`I-(1-β)W` 可逆。

**有界。** 若 `0 ≤ P ≤ 1`，则 `0 ≤ Π ≤ 1`。证明见测试 `bounded_output`。

**单调。** 若 `P ≤ P'`，则 `Π ≤ Π'`。证明见测试 `monotone_in_rating`。

## 2. 算法

### 2.1 精确解

`solve_exact(g, β)`，高斯消元，O(N³)。只用于小规模验证。

### 2.2 近似解

`solve_local(g, s, params)`，Local Push，O(1/eps)，与图规模无关。

思想：`Π[s] = β·Σ_v G[s][v]·P[v]`，其中 `G = (I-(1-β)W)⁻¹` 是 Green 函数，用残差推送近似。

每次从残差最大的节点 v 推送：
- 结果加 `β·r[v]·P[v]`
- 残差按 `(1-β)·r[v]·W[v]` 分给邻居

### 2.3 解析单个账户

`solve_local_single(g, s, u, params)`，只累加 u 那一列，省内存。

`Π[s][u]` 就是 s 视角下 u 的分数。

| BA | 60 | 348 | 204µs | 140µs | 3.6e-4 |
| BA | 100 | 588 | 561µs | 315µs | 6.1e-4 |
| WS | 100 | 678 | 492µs | 180µs | 6.3e-4 |
| ER | 100 | 390 | 459µs | 198µs | 5.1e-4 |

近似解在 eps=1e-4 时误差 < 1e-3，比精确解快一到两倍（N≤100 时精确解已经不慢）。

### 3.2 不动点残差

| 图 | 精确解 | 近似解 |
|---|---|---|
| BA | 8.9e-16 | 3.1e-4 |
| WS | 5.6e-16 | 2.9e-4 |

精确解达到机器精度，近似解残差与 eps 同量级。

### 3.3 收敛性

| eps | 最大误差 | 耗时 |
|---|---|---|
| 1e-2 | 1.2e-2 | 1.6µs |
| 1e-3 | 2.9e-3 | 3.3µs |
| 1e-4 | 3.4e-4 | 6.1µs |

误差随 eps 线性下降，验证了 Local Push 的理论界。

### 3.4 β 的影响

| β | 均值 | 标准差 | 极差 |
|---|---|---|---|
| 0.3 | 0.5118 | 0.0244 | 0.315 |
| 0.5 | 0.5117 | 0.0366 | 0.498 |
| 0.7 | 0.5116 | 0.0487 | 0.674 |
| 0.9 | 0.5115 | 0.0611 | 0.851 |

β 越大，个人判断权重越高，分数分化越大。均值不变（约 0.51，接近中性 0.5），说明系统整体无偏。

### 3.5 规模扩展

| N | 边数 | 单次求解 | 结果质量 |
|---|---|---|---|
| 100 | 588 | 16µs | 50.7 |
| 500 | 2988 | 186µs | 250.2 |
| 1000 | 5988 | 715µs | 496.6 |
| 2000 | 11988 | 1.84ms | 989.7 |

复杂度与边数近似线性，N=2000 时 1.8ms，手机端可接受。

结果质量（Π[s] 的行和）约等于 `0.5·N`，符合理论：稳态时行和等于 P 的行和。

### 3.6 抽样估计（范围化）

用 k 个随机样本估计全网均值，200 次试验的 RMSE：

| k | RMSE | 95% 误差 |
|---|---|---|
| 10 | 1.20e-2 | 2.36e-2 |
| 40 | 5.37e-3 | 1.05e-2 |
| 160 | 2.57e-3 | 5.04e-3 |
| 640 | 1.25e-3 | 2.45e-3 |

每把样本量翻四倍，误差减半，严格符合 1/√k。这是「抽查可以代替全网」的定量验证。

实际取 k=160 时，95% 误差约 0.5%，对社交排序足够。

## 3.7 攻击模拟

两种攻击，`cargo run --release --bin attack_report` 复现。

### 女巫攻击

注入 20 个女巫节点，内部完全图权重 10，每个连 2 个诚实节点。关键是让一部分诚实节点「被骗关注」女巫。

| 被骗比例 | 攻击前 | 攻击后 | 提升 |
|---|---|---|---|
| 0% | 0.5028 | 0.5028 | 0.00 |
| 5% | 0.5028 | 0.5068 | 0.01 |
| 10% | 0.5028 | 0.5112 | 0.02 |
| 20% | 0.5028 | 0.5175 | 0.03 |
| 50% | 0.5028 | 0.5450 | 0.08 |

**攻击的影响范围严格等于被骗比例。** 这是「以自己为中心」的核心性质：没有被骗的人完全不受影响，不会因为网络里有大量女巫而被稀释。

### β 对女巫攻击的抵抗

被骗 10%、女巫 20 个：

| β | 提升 |
|---|---|
| 0.3 | 10% |
| 0.5 | 5% |
| 0.7 | 2% |
| 0.9 | 1% |

个人权重越高，越难被操纵。β=0.7 把 10% 被骗的攻击效果从 10% 压到 2%。

### 信任潜伏

40 个潜伏者评分从 0.5 突变到 1.0（占 20% 节点）：

| β | 提升 |
|---|---|
| 0.3 | 7% |
| 0.5 | 4% |
| 0.7 | 3% |
| 0.9 | 1% |

潜伏攻击效率远低于女巫攻击。相同节点数下，女巫的效率是潜伏的 2 到 15 倍，因为女巫内部高权重放大了影响，而潜伏者混在正常图里，评分被稀释。

### 静态模型的盲区

潜伏攻击的「检测延迟」在静态模型里测不出来。当前实现没有时间维度，无法区分「一直这样」和「刚变成这样」。要检测突变，需要保存历史快照并比较，这是下一步的工作。

## 3.8 抽样语义说明

`[6]` 段的抽样是**全网均匀抽样**，用于验证 1/√k 的统计规律。

**不是**「邻域抽样」。以自己为中心的邻域抽样由 `solve_local` 本身实现：它按权重从自己出发有方向地探索边，本质是加权随机游走。两者的区别：

| 抽样方式 | 用途 | 实现 |
|---|---|---|
| 全网均匀 | 验证统计规律 | `simulate` 的 `[6]` |
| 邻域加权 | 实际计算 | `solve_local` |

### 模糊化：一个必须直面的矛盾

发布时只输出「分数向量」，不输出节点 ID。为了掩盖稀疏性，加拉普拉斯噪声：

| ε | 平均绝对误差 | 最大误差 |
|---|---|---|
| 100 | 9.8e-3 | 5.3e-2 |
| 50 | 2.2e-2 | 8.1e-2 |
| 20 | 5.4e-2 | 3.6e-1 |
| 10 | 1.1e-1 | 6.1e-1 |
| 5 | 1.8e-1 | 1.0 |
| 1 | 1.0 | 3.9 |

**这就是问题。** ε 小于 20 时，分数被噪声淹没，不可用。要可用，ε 必须 ≥ 50，但那样噪声尺度只有 0.02，隐私保护很弱。

原因在于敏感度：一个用户对所有人的评分向量，任意一格可以从 0 变到 1，敏感度为 1。拉普拉斯机制要求噪声尺度 ≥ 1/ε，所以 ε 小就意味着噪声大。

### 三个可选方向

**接受弱隐私。** ε=100，误差 0.01，噪声尺度 0.01。攻击者能从分数向量反推的精度也约 0.01，对社交关系推断意义有限。

**群体聚合后加噪。** 不发布单个用户的向量，发布 k 个用户向量的平均。敏感度降为 1/k，噪声尺度降为 1/(kε)，同样 ε 下精度提高 k 倍。代价是需要有人聚合，是半中心化的。

**换机制。** 随机投影可以做到「发布后不可还原」，但要求投影矩阵保密，于是需要点对点通信。这条回到了盲化因子的方案。

## 4. 用法

```rust
use social_trust::{Graph, solve_exact, solve_local, LocalPushParams};

let mut g = Graph::new(n);
g.add_edge(0, 1, 1.0);
g.set_rating(0, 1, 0.8);
g.finalize();

// 精确解（小图）
let pi = solve_exact(&g, 0.7);
let score = pi[0][1];

// 近似解（任意规模）
let params = LocalPushParams::default();
let row = solve_local(&g, 0, &params);
let score = row[1];
```

## 5. 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| β | 0.7 | 个人权重，越高越抗操纵，分化越大 |
| eps | 1e-3 | 精度，越低越准越慢 |
| max_iter | 50000 | 迭代上限，防不收敛 |

## 6. 已知边界

**评分均匀时结果趋中。** 如果 P 的缺失值用 0.5 填充，而大多数条目缺失，结果会趋近 0.5。这是数学事实，不是 bug。解决办法是让 P 更稀疏，只在有真实互动时赋值。

**孤立节点只受自己影响。** 没有出边的节点，`Π[s] = β·P[s]`，群体权重失效。这是定义的结果。

**不处理负值传播。** 当前 P 限定在 [0,1]，负信号（屏蔽）需要单独建模，不在本实现内。
