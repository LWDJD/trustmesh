场景：`Sybil{cluster:3}` / `Infiltrator`（带 1 个 Promoted）/ `Endorser{ratio:0.2}`（带 1 个 Promoted）。

### 1.1 本装置对 A6 实现做的两处修正（**读数字前必看**）

**① hm 的分母。** A6 的 `collect_rows`（`:548-552`）实际算的是 `hm = Σ(分布里出现的诚实账户) / 出现个数`，
而它给 S1~S4 的类均值用的是「该类账户总数、缺失按 0」——同一份报告里两套分母，成文定义写的是后者。
本装置按成文定义取 `hm = Σ / 活着的诚实账户总数`，**同时输出 `*_hp` 一族**（复刻 A6 的实现口径）。
换算关系：`hm_present = hm / present_frac`（`s1/s2/s3/s4/s5` 的 `_hp` 版就是这么来的）。

**② S3 的 1/β 解析下限。** β=0.3 时 `D[T] = β/N + (1−β)/N = 1/N` 而 `D[诚实] = β/N`，
所以只要观察者自己评过收益方、群体项把它顶满，比值必然 ≥ `1/β`。
β 是 f32，`0.3f32 = 0.30000001192…`，故实测 `s3_floor = 3.33333320`（**不是** 10/3）。
→ **S3 不是「过不过」，而是「离 3.33 多远」。**

差异来源（已定位，不是新漏洞）：
1. **P0① 分母口径**：群体项分母从「已缓存观点」变成「全部已评分来源」，覆盖率不足时群体项整体缩水，空/弱账户的相对基数被抬高；

3. 实测佐证：`hm`（成文口径）从旧 0.004489 掉到 0.004227（**−5.8%**），而分子几乎不动，比值自然上浮。

## 4. 必须单列的那一条：S2 注入女巫均值 +76%

这条差异**不是新漏洞**，是 P0① 分母口径的算术后果，链条如下：

```
P0① 前：group[u] = Σ_{有观点的来源} w_v·a_v / Σ_{有观点的来源} w_v
P0① 后：group[u] = Σ_{有观点的来源} w_v·a_v / Σ_{我评过的全部来源} w_v
```

注入女巫是**世界结束后**才 intern 的（P0③ 的 `mass_covers` 让它们在任何既有观点里读数为 0），
但**它们的份额在我评过的清单里**（注入者给它们各 1.0 分）。于是：

1. **分母变大** ⇒ 平均诚实账户的群体项变小 ⇒ `hm` 变小（实测 0.004489 → 0.004227，−5.8%）；
2. **注入女巫的分布值几乎不变**（它们本来就只有注入者那一份背书）；
3. 比值 = 分子/分母 ⇒ **分母变小 5.8% 不足以解释 76%**，还有第二层：
   女巫的份额从「不计入」变成「计入但投 0 票」，**同时把其他来源的相对权重稀释了**，
   而 `hm` 是全体诚实账户的平均，稀释对它和对女巫的影响不对称。

**结论**：S2 的判官阈值（越线率 = 0）**仍然通过**，但「注入女巫均值/hm」这个连续量从 3% 涨到 5.3%，
说明**预算封顶的强度下降了**。这需要作者/下一轮判断：0.05 是否仍算「够低」。

⚠️ **未完成归因**：上面第 3 点只是**候选解释**，我没有做单变量消融来证明它（例如：把 `mass_covers` 关掉但保留新分母，或反之）。
**报告不把推测写成结论。** 要做归因，需要一轮专门的对照实验（见 §6）。
