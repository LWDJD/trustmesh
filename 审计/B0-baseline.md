## 1. 判据与参数（逐字照抄 审计/A6-ablation.md 第 52-64 行 / 第 41-47 行）

| 判据 | 定义 |
|---|---|

| **S4** | 40 个「已 intern 但没人评分」的新密钥：均值 / hm、单点最高 / hm、出现率 |
| **S5** | 把已被诚实观察者评分的来源的观点换成伪造视图后，它自己的声望 ÷ 伪造前 |
| **S6** | 同输入重跑，全部（观察者 × 账户）声望矩阵的最大绝对差 |

参数：n_initial 200 / steps 100 / 4 轮 × 24h（now = 172）/ tick(k=12) / ViewParams 2048×5 seed=99 / Mean 聚合 / β=0.3 / H=72h / attack_ratio 0.08。
场景：`Sybil{cluster:3}` / `Infiltrator`（带 1 个 Promoted）/ `Endorser{ratio:0.2}`（带 1 个 Promoted）。

### 1.1 本装置对 A6 实现做的两处修正（**读数字前必看**）

**① hm 的分母。** A6 的 `collect_rows`（`:548-552`）实际算的是 `hm = Σ(分布里出现的诚实账户) / 出现个数`，
而它给 S1~S4 的类均值用的是「该类账户总数、缺失按 0」——同一份报告里两套分母，成文定义写的是后者。
本装置按成文定义取 `hm = Σ / 活着的诚实账户总数`，**同时输出 `*_hp` 一族**（复刻 A6 的实现口径）。
换算关系：`hm_present = hm / present_frac`（`s1/s2/s3/s4/s5` 的 `_hp` 版就是这么来的）。

**② S3 的 1/β 解析下限。** β=0.3 时 `D[T] = β/N + (1−β)/N = 1/N` 而 `D[诚实] = β/N`，
所以只要观察者自己评过收益方、群体项把它顶满，比值必然 ≥ `1/β`。
β 是 f32，`0.3f32 = 0.30000001192…`，故实测 `s3_floor = 3.33333320`（**不是** 10/3）。
→ **S3 不是「过不过」，而是「离 3.33 多远」。**

### 4.3 但「分子涨了」，不是「分母掉了」

把 `s2_ratio_hp` 拆成 `分布值 / hm_present` 的乘积，逐 seed 看：

| seed | PRE raw dist | MID raw dist | 变化 |
|---|---:|---:|---:|
| 11 | 0.00015280 | 0.00027750 | +81.6% |
| 12 | 0.00013624 | 0.00019767 | +45.1% |
| 13 | 0.00019185 | 0.00030949 | +61.3% |
| 14 | 0.00009148 | 0.00017039 | +86.3% |
| 15 | 0.00007401 | 0.00014541 | **+96.5%** |
| 16 | 0.00014498 | 0.00025114 | +73.2% |
| 17 | 0.00010066 | 0.00015367 | +52.7% |
| 18 | 0.00013404 | 0.00020417 | +52.3% |

**结论：`hm` 只变了 −0.39%，而注入女巫自己的分布值涨了 45%~97%。**
所以「分母缩小导致比值变大」这个候选解释**被证伪了**——真正变的是**分子的原始分布值**。

机理（由 P0① 的分母口径决定，不需要额外假设）：

```
PRE：group[u] = Σ_{有观点的来源} w_v·a_v(u) / Σ_{有观点的来源} w_v
FULL：group[u] = Σ_{有观点的来源} w_v·a_v(u) / Σ_{我评过的全部来源} w_v
```

对**诚实观察者**而言，`Σ_v w_v` 变大了（原来只算取到观点的十几份，现在算我评过的全部人）
⇒ **所有人的 group 项同时被缩小**。但缩小是**统一的**，而最终分布是 `query/Σquery` 归一化，
统一缩放本应互相抵消——抵消不掉的部分来自**个人项 β·personal[u]**：
个人项**没有**跟着缩小（它只看我自己的评分），所以归一化后，
**个人项占比高的人相对获益**。注入女巫恰好是纯个人项驱动的账户（诚实观察者根本没评过它们，
它们的值全部来自注入者那一份背书 + 群体项的二跳），而 `hm` 是**诚实账户**的均值、
诚实账户的个人项份额也是同一量级——于是稀释效应对两边的打击不对称，女巫被相对抬高。
