## 0. 结论（先读这段）

**1）机制对「绝对份额」有效，对「排名」无效。**
静态矩阵：N=3、λ=40 时 β_eff=0.9512，收益方 S3 倍数 24.31→2.50（−89.7%），
但收益方百分位 98.87→98.79（−0.08 个点），ρ 0.1167→0.1167（−0.00%）。
N=100、λ=40 时 S3 1.047→0.786（−24.9%），ρ 0.4756→0.4506（−5.3%）。

**2）代价是「清单外可见度」按 (1−β_eff) 坍缩。**
N=3、λ=40：清单外份额 69.25%→4.83%（保留 6.98%），冷门诚实账户的绝对份额只剩 6.98%。
但冷门账户的百分位变化只有 −0.0001 个点——因为排序是相对的，β_eff 只是把群体项整体缩放，
清单外账户之间的相对次序不变。**用百分位衡量会严重低估代价。**

**3）俘获实验：λ 压不住排名。**
混入 1 个被收买来源后，目标账户百分位抬升 N=3 53.41→52.43（λ=0→40）、
俘获份额倍数 196.7×→183.1×，基本不变。原因：目标不在观察者个人清单里，
带/不带俘获来源的声望都是 (1−β_eff)×群体项，比值与 β_eff 无关。
β_eff 只能把群体项整体调小，不能改变群体项内部谁排第一。

**4）耦合校验推翻了「ρ 几乎不变」的乐观结论。**
当所有节点都按 β_eff 发布观点（真实部署）时：
- N=10、λ=10：ρ 0.3807→0.2805（−26.3%），不是静态矩阵的 −0.03%。
- N=3、λ=5：配对逐 seed 的 ρ 变化为 −20.9% / −10.4% / −10.4%（均值 −13.9%）。
- N=100、λ=10：ρ 0.4830→0.4630（−4.1%）。
机理：群体项是「别人观点的加权平均」，别人的观点也按 β_eff 缩水，
质量信号大约按 (1−β_eff)² 衰减；静态矩阵只算了第一层 (1−β_eff)。

**5）λ 判定：不存在满足「S3 改善 ≥20% 且 ρ 下降 ≤3%」的区间。**
静态矩阵看起来存在（N≤10 全部 λ、N=20 λ≥10、N=50 λ≥20），但耦合校验下，
凡是 S3 改善 ≥20% 的点，ρ 都掉 4.7%~37.4%；唯一 ρ 掉得较少的 N=100 λ=10
只有 8.1% 的 S3 改善。**不要按静态矩阵的乐观数字上线。**

**6）变体 B 只在 M<N 时与 A 不同。**
主场景 N≤20 时 M=N，A=B；N=50/100 时 M=48（4 轮×12），B 的 β 更高
（N=100 λ=40：0.618 vs 0.500），S3 0.632 vs 0.786，ρ 0.4462 vs 0.4506。
M=3 子场景：λ=20 时 β_A=0.4167、β_B=0.9087；S3 0.853 vs 0.247；ρ 0.346 vs 0.322。
B 更保守，代价是 ρ 多掉约 3 个百分点。

## 1. 实验设计（为什么这样做）

### 1.1 机制与两个变体

    β_eff(N) = β + (1−β)·λ/(N+λ) = (β·N + λ)/(N+λ)

- 变体 A：N = 我评过的人数（正分清单规模）。
- 变体 B：M = 我成功取到观点的来源数（distinct source，按本轮实际 fetched 去重）。
- β=0.3、份额按分数、观点用压缩（buckets=2048, hashers=5, seed=99）全部不动；
  本实验只动 β_eff，不改库、不改 EngineConfig::default()。

### 1.2 世界与清单

World 配置：n_initial=400、steps=300、join/leave/dormancy 全 0、enable_rhythm=false、
follow_min/max=100/130、max_follows=140、follow_rate=0.02、interactions_per_step=2.0、
AttackKind::Infiltrator、attack_ratio=0.10。
探针确认：诚实存活账户的清单规模 mean=100.2、p10=88、p50=100、p90=118、max=140，
足以截出 N=100。

清单截断：每个存活账户的清单随机截到 N 条。
- 诚实观察者：纯随机 N 条；
- 攻击者：强制保留对 promoted 的攻击边（否则截断会以约 90% 概率丢掉攻击边，
  N=10 时 S3 会从 11.3 掉到 0.88——见 §8 风险 5）。

这不是「只改观察者」：N 是整个场景的「每人评几个人」。

### 1.3 静态重加权（主矩阵）与耦合校验（修正）

**静态重加权**：观点网络只用 β=0.3 跑一次（4 轮），然后用 β=0 的引擎精确取出
群体项 group，外部合成：

    rep = normalize(β_eff·personal + (1−β_eff)·group)

β 只出现在最后的 combine 里，所以这与「用 β_eff 重建引擎再查」逐位等价
（测试「合成与引擎逐位等价」）。8 seed、全 30 格、每格 64 个诚实观察者。
**代价**：它把「别人发布的观点」固定在 β=0.3，不含 λ 的反馈。

**耦合校验**：所有节点都用 β_eff 构造引擎并发布观点，直接读 trust_distribution。
3 seed × 选中格，每格 32 个诚实观察者。这是部署真实发生的版本。

报告里两个都给：完整矩阵用静态（8 seed，便宜），λ 判定用耦合（真实，但只有 3 seed）。
**两者不一致时以耦合为准**，§6 给出差异。

### 1.4 指标口径

| 指标 | 口径 |
|---|---|
| S3 收益方 | rep[promoted] ÷ mean(rep[诚实存活], 去掉观察者自己) |
| S3 攻击者 | mean(rep[40 个 Infiltrator]) ÷ 同一个诚实均值 |
| 绝对份额 | rep 已归一化到总和 1；收益方/诚实/攻击者各自取均值 |
| 原因子百分位 | promoted 在 401 个账户中的 midrank 百分位 |
| ρ | 每个观察者：rep vs world.quality 在 360 个诚实账户上的 Spearman；再对观察者取均值 |
| 跨 seed 方差 | 5 个固定质量档位（0.30/0.40/0.50/0.60/0.70）各取一个诚实账户；先算该账户在 64 个观察者上的均值 rep，再算 8 个 seed 的标准差；报 5 个目标的标准差的均值±标准差 |
| 俘获 +百分位 | 观察者清单里混入 1 个被收买来源（它只给捕获目标打 1.0）；目标百分位（带）−（不带），单位：百分点 |
| 俘获份额倍数 | 目标绝对份额（带）÷（不带） |
| 冷门 Δ百分位 | 被评分次数最低 25% 的诚实账户、且不在观察者清单里；λ 的百分位 − 同 N λ=0 的百分位（同 seed 配对） |
| 冷门份额比 | 同一批账户的绝对份额之比（λ / λ=0） |
| 清单外份额 | 观察者没评过的账户拿到的 rep 总和（= 1 − 个人清单份额） |

注意：mean(rep[诚实]) 包含观察者自己清单里的 N 个诚实账户，所以 β_eff 升高时
分母会被这 N 条个人项抬高。这是任务给的 S3 定义，但它意味着 **S3 比值的改善
有一部分来自分母膨胀，不全是攻击被压住**；§2.1 用原因子百分位交叉验证。

(1−β_eff)² 衰减。静态实验只测了第一层，所以 N=10 λ=10 的 ρ 看起来不变，实际 −26%。

## 8. 缺陷与风险清单

1. 静态视图设计会系统性高估 ρ（已量化）：N=10 λ=10 静态 −0.03%，耦合 −26.3%。
   本报告的全矩阵是静态的，λ 判定必须看 §6/§7.2。后续实验若只跑静态，
   请把 §6 的修正表一起带上。
2. Engine::on_view 的 total_mass 是 O(账户数) 全量扫描（已用 #[ignore] 测试记录）：
   每个观点都要对接收方认识的每个账户做一次 5-hash 查询。本实验 341s 里约一半以上
   花在这里；网络规模翻倍，取观点成本翻倍。真实部署的热点。
3. β_eff 无法改变群体项内部的排序（数学性质，不是 bug）：俘获实验里
   目标百分位 53.4→52.4、份额倍数 196.7×→183.1×，λ 基本无效。
   要防「单个被收买来源」，只能做来源级降权/审查，不能靠整体降 β。
4. S3 比值有分母膨胀：诚实均值包含观察者自己的 N 条个人项；β_eff 升高时
   这 N 条拿到 β_eff 的总份额，分母被抬高。N=3 λ=40 时 S3=2.50，
   但收益方百分位仍 98.79——比值改善不等于排名被纠正。报告同时给了 prom_pct。
5. 攻击者清单截断是「攻击者最优」假设：强制保留 promoted 攻击边。
   若纯随机截断，N=10 时 S3 从 11.3 掉到 0.88（攻击边大概率被截掉），
   λ 的收益会被高估/低估取决于假设。这是场景选择，已在 §1.2 写明。
6. 跨 seed 方差指标被「清单包含噪声」主导：N=3 时 5 个目标账户里任一被抽进
   某个观察者的清单，均值 rep 就跳一截。所以方差随 λ 几乎不变（0.0028→0.0027），
   不能读成「λ 稳定了估计」。
7. M=3 子场景的 S3 基线是 0.997：3 个随机来源没打中攻击者，所以 B 的
   「S3 0.247」不是压住攻击，而是「干脆不听这 3 人」。别把它当成防攻击收益。
8. 样本量：静态 8 seed × 64 观察者；耦合 3 seed × 32 观察者；
   M=3 48 观察者；俘获 48 观察者。耦合的 3 seed 只能看方向，不能给置信区间。
9. 异质人口只跑了静态，耦合版未跑；静态 −1.2% 的 ρ 变化不可外推。
10. total_mass 近似：接收方用自己认识的账户集合估计观点总质量；
    本实验所有引擎都 intern 全部 400 个账户，所以口径一致；真实的小圈子账户会有偏差。
